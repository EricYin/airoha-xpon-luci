PON 模式来自 U-Boot 的 onu_type bootarg 字节（不是 DTS）， SDK dump_pon_type_mode_info 官方解码： bits[1:0] = ONU 类型（1=SFU、2=HGU）， bits[7:4] = PON 模式（1=GPON、6=XGPON、7=XGSPON）。
本机 TTL 当前 61 = SFU+XGPON（uboot 仓库 README“61=HGU”是错的）； 出厂 71 = SFU+XGSPON。联通 HGU 家庭网关请用 62（HGU+XGPON）。
SFU 变体（x1/x0）没有 VEIP / LAN 侧组播引擎，SDK 组播收敛只对 HGU(0x2) 生效 （ra_nat_multicast.c），IPTV 组播请务必选 6x/7x 中的 HGU 值。
必须与 OLT 端口能力一致，切换后需重启并重新注册（LOID 已持久化，netifd 重启自动重放）。 选错可能导致无法 O5；恢复方法：U-Boot 提示符下 setenv onu_type 62; saveenv; reset。
